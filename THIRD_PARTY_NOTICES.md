# Avisos de terceros

## career-ops

El escáner semanal de vacantes (`scripts/escanear.mjs`, `.github/workflows/escaner-semanal.yml`) usa los proveedores de [career-ops](https://github.com/career-ops-hq/career-ops) para leer portales de empleo. El código no se copia a este repositorio: la tarea de GitHub Actions lo descarga fijo al commit `b564412d3b811df096dcb2eca7e5f19b234eafda` (versión 1.38.0). Centro STEM no usa la marca career-ops ni afirma una alianza con el proyecto.
